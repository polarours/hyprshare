hyprshare

Share anything, from the terminal to the desktop — without leaving Hyprland.

A Linux-native sharing platform for Hyprland & Wayland. File transfer, clipboard sync, screen capture and peer trust behind one CLI-first core. No cloud, no account.

Get started View on GitHub
⚠️ hyprshare is under active development and has not been officially released. Expect rough edges — testers and feedback are very welcome.

✨ One install, four front-ends

Every front-end calls the same CLI, so an action behaves identically everywhere.

⌨️ CLI

34 commands with JSON output — the single source of truth.

🖥️ TUI

A ratatui dashboard for device, inbox and clipboard.

🪟 Desktop GUI

A macOS-style Tauri window with light, dark and system themes.

🌐 Web UI

REST API plus a React frontend served by hyprshare web serve.

🎯 Features

Everything you need to move data between your Linux machines.

📦 File & folder sharing

Stage a session, serve it with a token, fetch from the peer. Checksums and verification built in.

📥 HTTP inbox

Receive uploads over LAN with token auth, extraction and transfer history.

📋 Clipboard

Read/write and cross-device sync with persistent history.

🖥️ Screen capture

xdg-desktop-portal + PipeWire, OBS fallback, MP4/WebM/MKV via ffmpeg.

🔐 TLS/mTLS

OpenSSL with self-signed X.509 v3 certificates.

🤝 Peer trust

Per-device identity, offline invitations, pairing and Avahi discovery.

🖼️ Screenshots

Real captures from the running app.

📦 Install & quick start

Arch Linux: one AUR package provides all four front-ends.

# install from AUR
yay -S hyprshare-git

# health check
hyprshare doctor

# stage and serve a file
hyprshare share file photo.jpg
hyprshare session serve <id> --generate-token

# receive on the peer
hyprshare session fetch <host:port> --token <t> --to ~/Downloads

hyprshare is built for Hyprland and Wayland. Everything is driven by the CLI — the TUI, desktop GUI and web UI are thin front-ends over the same commands.
